Roadmap

RepoDNA

Build a deep repository intelligence layer that transforms raw software history into structured knowledge for humans and AI agents.

Phase 0

Foundation

Goal: Turn a repository into structured data. No AI. No MCP. No Claude.

Input / Output

Input: Git Repository Output: Knowledge Store

Git Scanner

Collect: Commit Author Date Message Diff Example: { "commit": "abc123", "author": "John", "message": "Fix OOM issue", "files": ["scheduler.rs"] }

AST Scanner

Collect: Module Class Function Imports Example: { "function": "allocate", "file": "cache.rs" }

Dependency + Call Graph

Module A -> Module B allocate() ↓ get_free_block() ↓ evict()

repodna build .

.repodna/ commits.db functions.db dependencies.db

Phase 1

Repository Graph

Goal: Build the first Knowledge Graph.

Entities

Relationships

calls imports modifies introduced_in depends_on owns

repodna graph
Phase 2

Repository Search

Goal: Answer questions using the graph. No AI.

Query

repodna query "allocate"

Output

Function: allocate Introduced: commit abc123 Calls: get_free_block, evict Modified: 17 times

repodna inspect allocate
Phase 3

Historical Intelligence

Goal: Start understanding history. This is where LLM usage begins.

Commit Classification

"Fix OOM issue" -> {"type":"bug_fix","category":"memory"} "Replace FIFO with LRU" -> {"type":"architecture_change","from":"FIFO","to":"LRU"}

New Entities

Decision Incident Refactor Bug Fix Feature

repodna enrich

decisions.db incidents.db

Phase 4

Architecture Intelligence

Goal: Understand the repository like a Staff Engineer.

Module Meaning

cache -> purpose: GPU memory management, criticality: high scheduler -> purpose: request orchestration

Output Layers

Cache Layer Scheduler Layer Execution Layer Storage Layer

repodna architecture
Phase 5

MCP Server

Goal: Make it usable by agents.

Command

repodna serve

Tools

get_function_info get_commit_history get_decision_history get_module_summary get_architecture_summary

User: Optimize cache Claude: RepoDNA says cache is high risk Result: smarter code changes.

Phase 6

Agent Intelligence Layer

Goal: Let agents reason using Repository Memory.

New Tools

why_exists() refactor_risk() architectural_decisions() incident_history() ownership_info()

Behavior

Before changing code: "Why was this implemented?" RepoDNA answers with context.
