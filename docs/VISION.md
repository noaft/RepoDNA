# Vision

## RepoDNA

> Turn software history into structured knowledge for humans and AI agents.

---

Today, agents mostly see:

```text
Current State
```

RepoDNA aims to provide:

```text
Current State
+
Historical State
+
Architectural State
+
Decision State
```

---

Ultimate direction:

```text
Repository
      ↓
RepoDNA
      ↓
Knowledge Graph
      ↓
Claude Code
Cursor
Cline
Gemini CLI
OpenHands
Custom Agents
```

RepoDNA is not a coding assistant.

RepoDNA is the knowledge layer beneath coding assistants.

---

## North Star

One day, users can ask:

```text
Why does this code exist?
```

And get an answer like:

```text
Created in 2024

Original reason:
Prevent GPU memory fragmentation

Architectural decision:
Chosen over slab allocator

Related incidents:
Issue #421
Issue #517

Risk:
High
```
